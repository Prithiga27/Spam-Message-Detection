# Spam Message Detection using Machine Learning

## Project Overview
This project predicts whether a text message is spam or normal using Python and Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- CountVectorizer
- Multinomial Naive Bayes

## How It Works
1. Prepare labelled text messages.
2. Convert text into numerical features.
3. Train a Naive Bayes classification model.
4. Evaluate the model using test data.
5. Predict whether a new message is spam or normal.

## How to Run

Install dependencies:

`pip install -r requirements.txt`

Run the project:

`python spam_detection.py`

## Note
This is a beginner-level demonstration using a small sample dataset. A larger, more diverse dataset is needed for reliable real-world performance.
